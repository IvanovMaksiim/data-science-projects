## **Data science projects**

**01-data-cleaning-eda** — анализ рынка аренды Airbnb в Нью-Йорке (EDA, цены, районы, типы жилья, активность хостов, статистические тесты).

**02-dashboard-visualization** — интерактивный Tableau-дашборд по Airbnb: метрики, топ-хосты, цены по районам и типам, динамика бронирований, фильтры.

**03-breast-cancer-eda** — EDA и отбор признаков на датасете Breast Cancer Wisconsin, подготовка поднабора из информативных фич для классификации.

**Breast Cancer ML Pipeline** — контейнеризованный ML-пайплайн (Docker, Airflow, Kafka, Spark, MinIO, PostgreSQL) с классификацией и алертами в Telegram.

**a\b-test** — A/B-тест новой версии продукта: рост конверсии на ~3.7% (p < 0.00001), подтвержден логистической регрессией.

**adaptive_knn_kdtree** — кастомный KNN с KD-деревом, адаптивным k и взвешенным голосованием; показывает стабильное улучшение метрик над sklearn.

**breast-cancer-ml** — сравнение моделей (LogReg, SVM, Random Forest, XGBoost) для диагностики рака; ансамбли (Soft Voting) дают наилучший Recall и ROC-AUC.

**sql_exemple_analitics** — SQL-аналитика онлайн-магазина на синтетических данных: метрики, воронка продаж, поведение пользователей, топы товаров, временной анализ.

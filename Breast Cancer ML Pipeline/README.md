## **Breast Cancer ML Pipeline (Docker + Kafka + Spark + MinIO + PostgreSQL + Airflow)**

**Описание проекта**

Проект представляет собой полностью контейнеризованный ML-пайплайн для работы с данными по раку молочной железы. Он реализован с использованием Docker, оркестрации через Airflow и включает потоковую обработку данных через Kafka и Spark.

Проект демонстрирует полный цикл работы с данными: генерация данных, обработка, обучение моделей, сохранение результатов и уведомления через Telegram.

Основная цель — построить надежный и автоматизированный ML-пайплайн с мониторингом предсказаний.

**Цели**

1. Создать автоматизированный пайплайн для обработки и анализа медицинских данных.

2. Обеспечить потоковую генерацию данных на основе исходного датасета с добавлением небольшого шума.

3. Реализовать обучение и хранение моделей ML (Random Forest и Logistic Regression) с возможностью выбора лучшей модели через Grid Search.

4. Организовать хранение данных и моделей в MinIO и PostgreSQL.

5. Настроить уведомления в Telegram при обнаружении патологических случаев (класс 1) доступ к метрикам в начтоящий момент через бота.

6. Управлять оркестрацией пайплайна через Airflow: обучение раз в неделю и ежедневное предсказание новых данных.

**Архитектура и поток данных**

1. Генератор данных — создает новые данные на основе базового датасета (Breast Cancer) с добавлением небольшого шума.

2. Kafka — принимает потоковые данные в топики для обработки.

3. Spark Batch — агрегирует и обрабатывает потоковые данные, подготавливает их для ML моделей.

4. ML модели (Spark MLlib) — Logistic Regression и Random Forest для классификации.

5. MinIO — хранение обученных моделей, архивирование предыдущих версий.

6. PostgreSQL — хранение результатов предсказаний и исторических данных.

7. Telegram Bot — отправка уведомлений при обнаружении опасных случаев (класс 1).

8. Airflow — оркестрация: еженедельное обучение моделей на исторических данных, ежедневное предсказание новых данных.

**Используемые технологии**

* **Docker** — контейнеризация всех сервисов.

* **Airflow** — оркестрация пайплайна.

* **Kafka + Zookeeper** — потоковая генерация и доставка данных.

* **Spark (Batch + MLlib)** — обработка данных и обучение моделей.

* **MinIO** — хранение моделей и архивирование.

* **PostgreSQL + pgAdmin** — база данных для результатов.

* **Python (pandas, scikit-learn, pyspark)** — генерация данных, обработка и обучение моделей.

* **Telegram Bot API** — уведомления о критических событиях.

**Результаты**

* Автоматизированный ML-пайплайн, который обрабатывает потоковые данные и делает предсказания по вероятности наличия рака молочной железы.

* Подготовлены и сохранены модели Random Forest и Logistic Regression, с возможностью выбора лучшей модели через Grid Search.

* Все новые данные и предсказания централизованно хранятся в MinIO и PostgreSQL.

* Настроена система уведомлений о критических предсказаниях через Telegram.

* Полностью контейнеризированный проект с reproducible средой для разработки и продакшена.

**Выводы**

* Проект демонстрирует интеграцию потоковой обработки данных и batch ML моделей в одном пайплайне.

* Использование Docker и Airflow позволяет легко масштабировать и управлять компонентами проекта.

* Автоматическое архивирование моделей в MinIO и хранение результатов в PostgreSQL обеспечивает надежность и прозрачность работы ML моделей.

* Telegram-уведомления делают систему более интерактивной и позволяют оперативно реагировать на критические события.

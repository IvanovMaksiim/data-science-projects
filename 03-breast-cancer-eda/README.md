**Breast Cancer Diagnosis — Exploratory Data Analysis & Feature Selection**

Этот pet-проект посвящён исследованию и предварительной обработке датасета о диагностике рака груди (Breast Cancer Wisconsin Dataset).

Цель проекта — провести исследование признаков, выявить наиболее значимые для классификации и подготовить основу для построения моделей машинного обучения.

**Цели проекта**
1. Изучить структуру данных (размерность, наличие пропусков, дубликатов, распределение классов).

2. Выполнить разведочный анализ (EDA) признаков:

- распределения,

- нормальность,

- наличие выбросов,

- корреляции между признаками.

3. Провести стандартизацию для приведения признаков к сопоставимому масштабу.

4. Выбрать признаки с высокой предсказательной силой и низкой избыточностью.

5. Подготовить датасет для дальнейшего использования в моделях машинного обучения (Logistic Regression, Decision Tree, Random Forest, SVM, XGBoost).

**Ход работы**

- Загрузка и первичная очистка данных: удалены технические колонки (id, Unnamed: 32).

- Анализ распределения целевого признака: 63% доброкачественные, 37% злокачественные опухоли.

- Проверка нормальности (Shapiro–Wilk, Q-Q plots): все признаки имеют ненормальное распределение.

- Визуализация (histogram, boxplot, swarmplot, pairplot, heatmap) для поиска информативных признаков.

- Обнаружена сильная корреляция между многими признаками → проведён отбор, чтобы избежать мультиколлинеарности.

- Стандартизация признаков с использованием RobustScaler.

**Результаты**

1. Подготовлен нормализованный поднабор из 15 ключевых признаков с низкой избыточностью и высокой предсказательной способностью.

2. Определены признаки, хорошо разделяющие классы:

- concave points_mean, area_mean, concavity_worst, symmetry_worst, smoothness_mean и др.

3. Построены визуализации, подтверждающие различия классов по ключевым признакам.

4. Проект готов к следующему этапу — обучению моделей классификации и сравнению их качества.

**Используемые инструменты**

- Python: pandas, numpy, scipy, scikit-learn

- Визуализация: seaborn, matplotlib

- ML-модели (планируется): Logistic Regression, Decision Tree, Random Forest, SVM, XGBoost

**Вывод**

Данный pet-проект демонстрирует навык:

- полного цикла EDA (от загрузки данных до отбора признаков),

- грамотного применения статистических тестов,

- визуализации признаков и анализа их значимости,

- подготовки данных для машинного обучения.

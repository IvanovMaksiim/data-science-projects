## **Breast Cancer Classification ML Project**

**Описание проекта**  

Проект посвящен разработке и сравнению моделей машинного обучения для диагностики рака молочной железы на основе медицинских данных. Основная цель — построение надежных классификаторов, способных выявлять больных пациентов с высокой точностью и чувствительностью, минимизируя риск пропуска патологий.

**Цели проекта**

  * Изучить данные и провести предварительный анализ (EDA) для выявления закономерностей и особенностей признаков.

  * Сравнить различные алгоритмы классификации: логистическую регрессию, SVM, случайный лес, градиентный бустинг (XGBoost).

  * Оценить производительность моделей по ключевым метрикам (Recall, Precision, F1-score, ROC-AUC, Accuracy) с учетом несбалансированного распределения классов.

  * Применить методы ансамблирования (Hard и Soft Voting) для повышения качества классификации.

  * Найти оптимальные пороги классификации и параметры моделей с помощью GridSearchCV и F2-метрики, учитывая, что в медицинских задачах важнее Recall.

**Задачи проекта**

1. Подготовка данных:

    * Загрузка и объединение признаков и целевой переменной.
    
    * Масштабирование данных с помощью RobustScaler для моделей, чувствительных к масштабу признаков (Logistic Regression, SVM).

2. Построение базовой модели (DummyClassifier) для оценки минимального уровня метрик.

3. Разработка и обучение классификационных моделей:

    * Логистическая регрессия
  
    * SVM (линейное и RBF ядро)

    * Random Forest

    * XGBoost

    * Оценка моделей с помощью Stratified K-Fold cross-validation.

4. Ансамблирование моделей:

    * Hard Voting

    * Soft Voting (использование вероятностей предсказаний)

6. Подбор гиперпараметров и оптимальных порогов для улучшения метрик.

7. Визуализация результатов:

    * Confusion Matrix

    * Precision-Recall Curve

    * ROC Curve

    * Pie charts распределения предсказаний

**Используемые технологии и библиотеки**

* Python 3.x

* Pandas, NumPy — работа с данными

* Scikit-learn — алгоритмы машинного обучения и метрики

* XGBoost — градиентный бустинг деревьев

* Matplotlib, Seaborn — визуализация

* Jupyter Notebook — разработка и исследование

**Результаты проекта**

* Базовая модель (DummyClassifier) показала минимальный уровень метрик: Accuracy ~0.60, Recall ~0.40 для класса «больной».

* Наилучшие результаты среди отдельных моделей показали ансамблевые методы:

    * XGBoost: Recall = 0.95, Precision = 0.97, F1 = 0.96, ROC-AUC = 0.989

    * Random Forest: Recall = 0.93, Precision = 0.97, F1 = 0.95, ROC-AUC = 0.991

* Soft Voting ансамбль достиг Recall = 0.95, Precision = 0.988, Accuracy = 0.975, ROC-AUC = 0.994, что делает его лучшим методом для практического применения.

* Hard Voting показал высокую точность, но немного уступает Soft Voting по чувствительности и ROC-AUC.

* Оптимизация порогов и гиперпараметров с использованием F2-метрики позволила увеличить полноту выявления больных пациентов.

**Выводы**

* Ансамблирование моделей (особенно Soft Voting) значительно повышает качество классификации, улучшая Recall и устойчивость к несбалансированным данным.

* Линейные модели (Logistic Regression, SVM Linear) также демонстрируют хорошие результаты, но уступают ансамблям по чувствительности.

* Нелинейный SVM (RBF) менее эффективен на текущих данных.

* Для медицинских задач, где критично выявлять всех больных пациентов, использование Soft Voting и оптимизация порогов на основе F2-метрики является наиболее подходящей стратегией.
